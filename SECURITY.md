# Security Policy

## Reporting a vulnerability

Please open a private GitHub security advisory instead of a public issue when
reporting a potential vulnerability.

Do not include passwords, API tokens, private hostnames, or production network
details in reports, issues, screenshots, or commits.

## Safe operation

Live mode should only be used against systems the operator owns or is
authorized to monitor. Secrets must be supplied through environment variables
and must never be committed to the repository.
